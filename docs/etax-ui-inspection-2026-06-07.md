# 自然人电子税务局界面记录

检查日期：2026-08-07。测试机构：广发证券股份有限公司广州万博证券营业部。所属月份已在税局页面验证 `2026年6月`、`2026年7月`，页面结构和操作菜单一致。

## 通用结构

- 左侧主菜单：扣缴申报、集中申报。
- 扣缴申报子菜单：人员信息采集、专项附加扣除信息采集、个人养老金扣除管理、公益慈善捐赠信息采集、综合所得申报、分类所得申报、非居民所得申报、限售股所得申报、税款缴纳、退付手续费核对、优惠备案与信息报送、查询统计、个人代开发票。
- 申报明细页通常包含：税款所属月份、返回、添加、导入、导出、重新算税、更多操作、查看导出记录、查询、分页。
- 导入按钮下拉项：导入文件、模板下载。
- 导入窗口标题为“文件导入”，包含“新增导入”“导入结果”两个页签和“选择文件”按钮；不会在窗口内清空数据。
- 导入窗口提示：文件大小通常不超过 5M；处理中任务达到 10 个时暂停新增导入；已有人员导入会覆盖已有信息。专项附加扣除还要求多个批量文件压缩为不含文件夹的 zip。
- 月份选择器使用 Element UI 月份面板，2026 年可选 1 月至 12 月；本次已验证 6 月和 7 月并恢复到 7 月。

## 综合/分类所得入口

综合所得申报和分类所得申报入口首先展示汇总表，行项目是可点击链接：综合所得包含正常工资薪金、全年一次性奖金、内退一次性补偿金、解除劳动合同一次性补偿金、个人股权激励收入、年金领取、提前退休一次性补贴、劳务报酬（适用/不适用累计预扣法）、稿酬、特许权使用费等；分类所得包含利息股息红利、财产租赁、财产转让、偶然所得等。进入具体行后才出现导入和清空菜单。

## 工资页按钮组件

- “重新算税”是带 `aria-haspopup="list"` 的下拉按钮，选项为“选中人员”“全部人员”。本次未点击选项，避免触发重算。
- “导出”是带下拉箭头的导出下拉按钮；旁边有“查看导出记录”。本次只读取按钮 DOM，未触发下载。
- “查询”是文本按钮，打开查询条件区域/弹窗；包含姓名、完整证件号码等筛选输入和复选框。
- “更多操作”是 Element UI dropdown，菜单通过 `ul.el-dropdown-menu.el-popper` 渲染，菜单项为 `li.el-dropdown-menu__item`。

## RPA 选择器结论

- “清空数据”真实 DOM：`ul.el-dropdown-menu.el-popper:visible li.el-dropdown-menu__item`，文本为“清空数据”。
- 人员信息采集、专项附加扣除页面没有“清空数据”，RPA 遇到这两类任务不能因找不到清空菜单而失败。
- 综合所得和分类所得的导入明细页才有清空菜单；限售股虽然有清空菜单，但本需求明确不清空。
- 单位切换弹窗是 `dialog` + `radiogroup`，同名机构对应多个 `radio`；应按维护表中的 `RPA搜索结果序号`（从 1 开始）选择，不得默认第一条。
